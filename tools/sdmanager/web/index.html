Manage your emu8 SD card over USB

Plug the board into this computer, click Connect and pick its serial port. You can then browse the card, upload ROMs and disk images, download saves and tidy up folders without removing the card.

This browser cannot open serial ports. Use a recent Chrome, Edge or Opera on Windows, macOS, Linux, ChromeOS or Android, or use the command-line tool tools/sdmanager/emu8sd.py.

  • Close any other serial monitor (Arduino IDE, PlatformIO, PuTTY) first: only one program can hold the port.
  • The emulator keeps running while you transfer. Avoid replacing the disk image that is currently mounted.
  • Some boards restart when the port opens. The app waits for the board to finish booting.
