# emu8 - C64 joystick map
#
# Copy this file to the SD card as /emu8/c64/joymap.txt (or /c64joymap.txt) and edit it to choose which
# keys steer and fire the C64 joystick. It is read when the C64 boots. Every line below is the
# BUILT-IN DEFAULT, so this file as shipped changes nothing; only lines that differ from the default
# count (up to 64 of them). Deleting a line does not unmap the key, it just leaves the default; use
# "= NONE" to take a key off the stick. Errors are reported in the log ("C64 joymap line N: ...")
# and the line is skipped.
#
# The C64 menu edits it too: CONFIG > JOYSTICK (on the PicoCalc a picture of its keyboard over a
# joystick: red button 1 = FIRE, 2 = FIRE2, the small 3 = FIRE3; elsewhere a list). A change there
# is live at once and rewrites /emu8/c64/joymap.txt with only the changed keys.
#
# The map is used while JOYSTICK is ON in the C64 menu, on the port JOY PORT selects. It applies to
# every keyboard that reaches the C64 through the HID path: the PicoCalc's built-in keyboard, a USB
# keyboard (JC4827W543 / JC1060P470), and the PC keyboard in the desktop build. A key on the stick
# still types its C64 key as well (docs/c64-keymap.txt), as the arrows always have; the exception
# is SHIFT, which is kept off the C64 keyboard while it fires and no typing key is held.
#
# FORMAT
#   <host key> = <joystick action>      # comment
#
#   Any number of keys may pull the same line; keys held together add up (UP and LEFT = UP+LEFT).
#
# HOST KEYS (names are not case-sensitive; the same as docs/c64-keymap.txt, plus SHIFT)
#   A..Z  0..9  F1..F12  SPACE ENTER ESC BACKSPACE TAB DELETE INSERT HOME END PAGE_UP PAGE_DOWN
#   UP DOWN LEFT RIGHT PAUSE (= BREAK) CAPSLOCK PRINTSCREEN SCROLLLOCK NUMLOCK
#   MINUS EQUAL LBRACKET RBRACKET BACKSLASH NONUS_HASH SEMICOLON APOSTROPHE GRAVE COMMA PERIOD SLASH
#   KP_0..KP_9 KP_PLUS KP_MINUS KP_MULTIPLY KP_DIVIDE KP_PERIOD KP_ENTER
#   CTRL  ALT  SHIFT the modifiers (either side; ALT also takes the GUI/Windows key)
#   0xNN             any HID usage code, in hex
#
# JOYSTICK ACTIONS
#   UP DOWN LEFT RIGHT
#   FIRE
#   FIRE2 FIRE3      a 2/3-button joystick's extra buttons. They sit on the paddle lines (SID POTX /
#                    POTY read $00 while held, $FF otherwise), so only programs written for such a
#                    joystick see them. Either port's paddle select reads them.
#   NONE             the key does not touch the stick
#
# PicoCalc notes: the menu keys (Ctrl-F1 ...) are not remapped here.

# ---- the stick ----
UP = UP
DOWN = DOWN
LEFT = LEFT
RIGHT = RIGHT

# ---- the buttons ----
RBRACKET = FIRE
LBRACKET = FIRE2
EQUAL = FIRE3
