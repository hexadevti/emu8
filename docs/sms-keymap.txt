# emu8 - Sega Master System keyboard map
#
# Copy this file to the SD card as /emu8/sms/keymap.txt (or /smskeymap.txt) and edit it to remap keys.
# It is read when the SMS boots. Every line below is the BUILT-IN DEFAULT, so this file as shipped
# changes nothing; only lines that differ from the default count (up to 64 of them). Deleting a
# line does not unmap the key, it just leaves the default; use "= NONE" to make a key do nothing.
# Errors are reported in the log ("SMS keymap line N: ...") and the line is skipped.
#
# The SMS menu edits it too: CONFIG > KEYBOARD (on the PicoCalc a picture of its keyboard over an
# SMS control pad; elsewhere a list). A change there is live at once and rewrites
# /emu8/sms/keymap.txt with only the changed keys.
#
# Applies to every keyboard that reaches the SMS through the HID path: the PicoCalc's built-in
# keyboard, a USB keyboard (JC4827W543 / JC1060P470), and the PC keyboard in the desktop build.
# A gamepad is not affected. PAUSE (F11 / Ctrl-F3) is a console button and is not remapped here.
#
# FORMAT
#   <host key> = <SMS button>      # comment
#
#   Any number of keys may press the same button. The SMS has no SHIFT: a key is the same button
#   with or without it (the PicoCalc's Shift-F1.. / Shift-arrows arrive as other keys - F6.., PAGE_UP
#   - and can be mapped on their own).
#
# HOST KEYS (names are not case-sensitive; the same as docs/c64-keymap.txt)
#   A..Z  0..9  F1..F12  SPACE ENTER ESC BACKSPACE TAB DELETE INSERT HOME END PAGE_UP PAGE_DOWN
#   UP DOWN LEFT RIGHT PAUSE (= BREAK) CAPSLOCK PRINTSCREEN SCROLLLOCK NUMLOCK
#   MINUS EQUAL LBRACKET RBRACKET BACKSLASH NONUS_HASH SEMICOLON APOSTROPHE GRAVE COMMA PERIOD SLASH
#   KP_0..KP_9 KP_PLUS KP_MINUS KP_MULTIPLY KP_DIVIDE KP_PERIOD KP_ENTER
#   CTRL  ALT        the modifiers (either side; ALT also takes the GUI/Windows key)
#   0xNN             any HID usage code, in hex
#
# SMS BUTTONS (control pad 1)
#   UP DOWN LEFT RIGHT
#   1                button 1, also START (also accepted: START, BUTTON1)
#   2                button 2 (also accepted: BUTTON2)
#   NONE             the key does nothing
#
# PicoCalc notes: the menu keys (Ctrl-F1 ...) are not remapped here.

# ---- the D-pad ----
UP = UP
DOWN = DOWN
LEFT = LEFT
RIGHT = RIGHT

# ---- the buttons ----
LBRACKET = 1
RBRACKET = 2
