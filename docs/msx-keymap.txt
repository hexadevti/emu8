# emu8 - MSX1 keyboard map
#
# Copy this file to the SD card as /msx/keymap.txt (or /msxkeymap.txt) and edit it to remap keys.
# It is read when the MSX boots. Every line below is the BUILT-IN DEFAULT, so this file as shipped
# changes nothing; only lines that differ from the default count (up to 64 of them). Deleting a
# line does not unmap the key, it just leaves the default; use "= NONE" to make a key do nothing.
# Errors are reported in the log ("MSX keymap line N: ...") and the line is skipped.
#
# The MSX menu edits it too: CONFIG > KEYBOARD (on the PicoCalc a picture of an MSX1 keyboard,
# Philips VG-8020 style; elsewhere a list). A change there is live at once and rewrites
# /msx/keymap.txt with only the changed keys.
#
# Applies to every keyboard that types into the MSX through the HID path: the PicoCalc's built-in
# keyboard, a USB keyboard (JC4827W543 / JC1060P470), and the PC keyboard in the desktop build.
#
# FORMAT
#   <host key> = <MSX key> [+SHIFT | -SHIFT]      # comment
#
#   +SHIFT    hold the MSX's SHIFT while the key is down       (END = HOME +SHIFT, CLS)
#   -SHIFT    release the MSX's SHIFT while the key is down    (KP_1 = 1 -SHIFT)
#   neither   SHIFT is passed through as typed
#
#   "SHIFT+<host key>" is a rule for that key typed with SHIFT; it wins over the plain rule for the
#   key, and releases the MSX's SHIFT unless +SHIFT is given.
#
# HOST KEYS (names are not case-sensitive; the same as docs/c64-keymap.txt)
#   A..Z  0..9  F1..F12  SPACE ENTER ESC BACKSPACE TAB DELETE INSERT HOME END PAGE_UP PAGE_DOWN
#   UP DOWN LEFT RIGHT PAUSE CAPSLOCK PRINTSCREEN SCROLLLOCK NUMLOCK
#   MINUS EQUAL LBRACKET RBRACKET BACKSLASH NONUS_HASH SEMICOLON APOSTROPHE GRAVE
#   COMMA PERIOD SLASH
#   KP_0..KP_9 KP_PLUS KP_MINUS KP_MULTIPLY KP_DIVIDE KP_PERIOD KP_ENTER
#   CTRL  ALT        the modifiers (either side; ALT also takes the GUI/Windows key).
#                    SHIFT is always the MSX's SHIFT and cannot be remapped.
#   0xNN             any HID usage code, in hex
#
# MSX KEYS (the international MSX1 matrix)
#   A..Z  0..9  MINUS EQUAL BACKSLASH LBRACKET RBRACKET SEMICOLON APOSTROPHE GRAVE COMMA PERIOD
#   SLASH DEAD (the dead key / accent key)
#   (- = \ [ ] ; ' ` , . / are accepted for the punctuation)
#   SHIFT CTRL GRAPH (GRPH) CAPS (CAPSLOCK) CODE (KANA)
#   F1..F5 (F6..F10 are SHIFT + F1..F5, as on the MSX)
#   ESC TAB STOP BS (BACKSPACE) SELECT RETURN (ENTER) SPACE
#   HOME (CLR_HOME) INS (INSERT) DEL (DELETE) LEFT UP DOWN RIGHT
#   NONE             the key does nothing
#
# PicoCalc notes: its F3 key arrives as F12 and Shift-F1..F4 as F6..F9, so on the PicoCalc the
# default has "F12 = F3" in place of the "F3 = F3" below. F10 opens the menu everywhere, so F6..F10
# of the MSX are F6..F9 and F11. With JOYSTICK on, the arrows and SPACE (and the PicoCalc's SHIFT)
# also drive the joystick (docs/msx-joymap.txt). The menu keys (Ctrl-F1 ...) are not remapped here.
